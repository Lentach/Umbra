## What was done
- **C3:** the six faces the app draws (Inter 400/500/600/700/800, Archivo 900) ship in `frontend/assets/google_fonts/`, byte-identical to what google_fonts 8.2.1 fetched (sha256 checked against the package), with the OFL texts. `main()` sets `GoogleFonts.config.allowRuntimeFetching = false`. google_fonts finds a face by file name (`Inter-SemiBold.ttf`, case-sensitive); with fetching off, a missing one renders in the platform font. The unused `RpgTheme.pressStart2P` was deleted. Weights were enumerated with a paren-matching scan of every `bodyFont`/`screenHeaderTitle`/`GoogleFonts.*` call; italics are only `copyWith` (synthesized).
- **Test environment change:** bundled fonts now load in `flutter test` too, asynchronously at first use, so text metrics depended on test order (`bubble_redesign_test` failed on Inter widths). New `test/flutter_test_config.dart` loads all six faces before every file (it is also the bundle check: a missing face fails every file). The bubble test now compares the surface to its Wrap (text + inline time) instead of an Ahem-era wrap assumption.
- **D6:** `ChatPresenceService`, `TypingDto`, `RecordingVoiceDto`, the gateway handlers and `isUserOnline` are deleted; the client's `partnerTyping`/`partnerRecordingVoice` listeners and their 2 tests too. No client emits either event since Phase 4 step 5 (`88d24ddd`). An old client's emit is unanswered; nothing awaited an ack.
- **D5:** `.github/workflows/secrets.yml` (own workflow, because `ci.yml`'s `paths-ignore` skips docs-only pushes, where the one real historic leak was). gitleaks 8.30.1 is pinned with its checksum; it scans the full history on every master push and PR. The 20 historic findings over the full history were reviewed one by one, all dead or placeholders; they are fingerprinted in `.gitleaksignore`. The one real secret, `CONTACT_INBOX_KEY` in a July summary, was rotated in `10f733d1`; prod's key differs (compared on the VM, the value was not printed).
- **D1:** backend lock written with npm 10 (node:22 container; the host's npm 11 would add `libc` churn).
  - Runtime: undici 7.30.2 (direct `^7.30.1`), body-parser 2.4.0, qs 6.17.1, grpc-js 1.14.7, fast-xml-parser 5.12.1, proxy-addr 2.0.8.
  - multer 2.5.0: it can't be removed (`@nestjs/platform-express` needs it), so the override floor was raised.
  - Dev deps updated within their ranges, in the backend and smoke locks.
  - Left: deepmerge (no fix), smoke msal-node (needs a major).
