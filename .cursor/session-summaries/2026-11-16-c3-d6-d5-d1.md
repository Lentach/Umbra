## What was done
- **C3** (details: plan row C3, `frontend/CLAUDE.md` §9): six faces (Inter 400–800, Archivo 900) bundled, byte-identical to google_fonts' downloads; `main()` turns runtime fetching off; the unused `pressStart2P` was deleted. Weights came from a paren-matching scan of every `bodyFont`/`screenHeaderTitle`/`GoogleFonts.*` call; italics are only `copyWith`, so they are synthesized.
- **Test environment change:** bundled fonts now load in `flutter test` too, asynchronously at first use, so text metrics depended on test order (`bubble_redesign_test` failed on Inter widths). New `test/flutter_test_config.dart` loads all six faces before every file (it is also the bundle check: a missing face fails every file). The bubble test now compares the surface to its Wrap (text + inline time) instead of an Ahem-era wrap assumption.
- **D6:** `ChatPresenceService`, `TypingDto`, `RecordingVoiceDto`, the gateway handlers and `isUserOnline` are deleted; the client's `partnerTyping`/`partnerRecordingVoice` listeners and their 2 tests too. No client emits either event since Phase 4 step 5 (`88d24ddd`). An old client's emit is unanswered; nothing awaited an ack.
- **D5** (details: plan row D5): `.github/workflows/secrets.yml` is its own workflow, because `ci.yml` skips docs-only pushes, where the one real historic leak was. The 20 historic findings over the full history were reviewed one by one, all dead, and are fingerprinted in `.gitleaksignore`. Prod's `CONTACT_INBOX_KEY` differs from the leaked July value (compared on the VM; the value was not printed).
